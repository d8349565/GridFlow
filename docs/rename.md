# 按表格内容批量重命名

顶部的「Excel 汇总」和「批量重命名」分别进入各自工作区。重命名使用独立文件清单，不把原文件复制进汇总数据库；原文件只在核对并确认执行后改名，工作簿内容不重写。

此功能为当前源码新增内容，尚未包含在已有发行包中。

## 日常操作

1. 添加或拖入 `.xlsx` / `.xls` 文件，也可添加多个文件夹。默认包含子文件夹，临时文件和文件链接会忽略。
2. 在原表预览中点击单元格，选择「加入文件名」。可切换工作表，多次选取；右侧按顺序组合内容，支持前后缀、分隔符、固定文字和小数位数。
3. 底部显示当前文件的新名称，修改规则后自动更新。点击「核对全部文件名」，逐一查看原名、新名、冲突及校验结果，再确认执行。

每个工作簿都使用同名工作表、相同坐标取值。单元格默认按原值命名：文本编号的前导零保留；数字的 Excel 显示格式不自动带入，可显式设置小数位。合并单元格取左上角。公式使用 Excel 已保存的结果，不重新计算；没有缓存值时跳过并说明如何处理。

规则自动保存在当前应用的本机存储中，文件清单在当前程序会话中保留。一次最多 10000 个文件，单文件不超过 100MB；长清单和核对结果每页显示 100 项。

切换工具后保留已勾选的文件，包括用户主动取消全部选择的状态。继续添加文件时，原先排除的文件不会重新选中。

## 配置区与侧栏宽度

右侧分为「文件名格式」「文件名组成」「内容校验」三组。每条命名规则和校验独立成块，依次显示用途、取值位置、参数和当前文件的效果；工作表名与单元格地址分行显示，长名称不会挤压字段标签。校验内部的多个合计区域另有编号和分隔。

拖动文件列表与原表之间、原表与规则区之间的分隔线，可以分别调整左右侧栏宽度。宽度会在本机记住；双击对应分隔线恢复默认，聚焦分隔线后也可用左右方向键微调。窗口变小时会保留原表的最小预览空间，避免整个界面出现横向溢出。侧栏宽度仅是本机界面偏好，不写入加密的业务配置。

## 本机配置与跨电脑使用

顶部「保存配置」将命名内容、完整对照表、校验、单位换算和条件标签一起保存到软件的本机配置库。第一次输入名称即可保存，不选择文件位置、不输入密码；已有配置可直接更新，也可勾选「另存为一份新配置」。

下次点击「本机配置」，按名称选择「使用配置」。配置库独立于自动草稿，保留多份命名方案；应用配置会替换当前规则，文件清单保持不变。文件清单和输出位置按本次任务选择，不随命名方案保存。本机规则及对照正文使用 Windows 账号加密保存，列表仅显示名称和更新时间。

换电脑时，在「本机配置」中点击「导出当前配置」，设置至少 8 个字符的密码，保存为 `.gfrcfg` 文件。在另一台电脑的「本机配置」中点击「导入配置文件」，输入密码即可应用，并自动加入本机配置列表；同名时生成新名称，不覆盖原有方案。导出文件不绑定 Windows 账号，完整对照表随配置迁移。密码不正确或文件损坏时，当前规则保持不变；忘记密码将无法打开此文件。

本机草稿继续加密自动保存，并在离开工作区和退出前保存最新修改。退出前保存失败会保留窗口，可返回编辑、重试，或「导出配置后退出」。旧明文草稿在成功迁移为加密草稿后移除。

保存、导入等操作完成时，在右下角显示简短通知，约 5 秒后自动收起。悬停或聚焦会暂停，也可手动关闭；警告和错误保持可见。

## 集中保存到一个文件夹

左侧「文件存放位置」默认「在原文件夹改名」。需要汇集多层目录时，选择「集中到一个文件夹」并选择目标文件夹：

- 默认勾选「保留原文件（复制）」，重命名后复制到目标位置，原文件保留。
- 取消勾选则移动到目标文件夹。跨盘时先完整写入、同步和核对目标，再移除原文件；移除失败时保留两份并明确说明。
- 默认「重名时自动编号」，例如 `预算.xlsx`、`预算 (2).xlsx`。目标文件夹已有名称和本批重名都会避让；取消自动编号则跳过冲突文件。

「核对全部文件名」会列出最终文件名和完整目标路径，确认后才执行。即使核对后突然出现同名文件，也不会覆盖。记录可「撤销副本」或「恢复原位」；副本仅在原文件仍存在且两边均未变化时移除，移动恢复时不覆盖已占用的原路径。

## 可选的对照信息

点选编码单元格后选择「添加对照」，从 Excel 复制编码、客户简称、生产线名称等多列内容。指定查找列，勾选需要加入文件名的列，可以一次添加多个字段；对照表和当前文件名均可预览。

支持 Excel 剪贴板的制表符、带引号的换行内容及引号转义。重复编码、空编码和空对照值会阻止添加。查不到编码时默认跳过该文件，也可为单个对照字段设置备用文字。对照匹配保留编号前导零，忽略两端空白，不做模糊匹配。

## 可选的校验和标签

- **金额 / 数量校验**：先点击「添加校验」，再到原表选择填报总额或数量的单元格，点击「确认填写值」；随后跨工作表框选明细区域并确认。若只选一个单元格，则合计该列从此行到表尾；框选区域则按固定边界计算。
- **单位换算**：设置「换算除数」，例如件数除以 1000 后，与以千件填写的总量比较。
- **多区域相加**：一个校验可加入多个合计区域，例如销售计划金额加上 CPU 金额。
- **行筛选**：可设置整行至少有几格非空内容，0 表示不过滤。合计区域中的非空非数字、Excel 错误和无缓存公式会导致该文件跳过，避免把错误内容默认为零。
- **计入条件**：可点选一个单元格，选择大于零、有内容、等于指定值；满足条件时才计入对应合计区域。
- **容差和异常名称**：默认允许 1% 相对误差，边界包含在内。填写值为零时，合计也需为零（保留浮点计算容差）。不一致时在文件名前加入用户设置的标签，例如「金额异常_」「数量异常_」；核对列表可筛选这些问题。校验不一致会标记名称，读取错误则跳过。
- **结果显示精度**：新生成的校验说明中，合计、填写值和容差显示两位小数；计算和是否一致的判定仍使用原始精度，不先把数值四舍五入。
- **条件标签**：先点击「条件标签」，再在原表选择依据单元格，点击「确认条件单元格」后设置标签文字和条件，例如 C35 大于零时加入「【CPU】」。

进入选格模式后会清除上一次的选区，显示当前候选位置及内容，确认后才绑定。已绑定的条件、填写值和合计区域可点击「重选」修改；取消或按 Esc 保留原绑定。

年度、工作表名、单元格坐标、对照字典和业务标签均由用户配置，不硬编码示例脚本中的生产线资料。

## 执行、日志与恢复

核对阶段不修改文件。同名目标、本批重名、缺表、空命名值、无匹配对照、保留名称及超长路径等会在列表中说明。非法文件名字符会替换为下划线，修改后的名称在执行前可见。原扩展名保持不变；选择原文件夹改名时不改变所在目录。

执行前会保存恢复记录，每个文件改名前后都更新日志。执行时再次核对源文件的大小和修改时间；Windows 使用不覆盖目标的系统改名操作，防止核对后突然出现同名文件。单个文件被占用、权限不足或发生变化时记录失败并继续其他文件。

可停止扫描、核对、改名和恢复；复制期间会按数据块响应停止，保留已经完成的结果。处理过程中关闭窗口会提示先停止任务。恢复记录位于应用数据目录的 `rename-history`，通过「上次记录与恢复」打开最近一轮，包括重启后的记录。原名被占用、文件已改变或中断后状态无法确认时，不自动覆盖，需人工核对。

「保存日志与汇总」导出两个工作表：

- 「重命名日志与汇总」：原名、新名、实际状态、原因、来源路径、目标路径、取值明细和校验结果。
- 「提取信息」：按命名字段分列，其中对照字段使用粘贴表的列名。

日志导出不覆盖已有同名文件。恢复记录属于本地数据，保留它才能在应用重启后恢复最近一轮文件名。
