# 汇格 · GridFlow v2.0.0 验证记录

2026-10-11。正式版本采用已由用户确认的 汇格 · GridFlow；内部开发构建号不作为本次 Git 发行版本。迁移到仓库根目录只调整入口、文件路径和版本元数据，不改变已确认的业务流程。

根目录迁移后，Rust 10 项回归、前端 6 项检查和前端生产构建通过。后续按用户要求停止追加测试和打包；本次提交不附带重新制作的便携包。

## 已有功能验收

- Rust 原生回归 10 项：五个原始 XLSX、XLS、不同编码 CSV、多层表头、原格式、前导零、数值和日期、同名来源提取、隐藏/重命名、空值与零值、透视及加权平均、筛选导出、公式缓存异常、取消、密码、恢复与清理。
- 前端契约与格式检查 6 项，界面流程 12 项：配置/结果切换、选区与新列、格式建议、筛选保存、设置复用、键盘操作、侧栏收起、紧凑文件列表、多工作表选择、长列表滚动与焦点恢复。
- Windows 11 实机：32 份销售报表合并 960 行、12 个业务列，32 份费用申报合并 800 行、8 个业务列，导出逐值与源文件一致。
- 两个原格式工作簿合并 6 行；22 磅标题、合并表头、日期、金额、百分比、负数颜色和前导零保留。资源来自本地 Tauri 资源与 IPC。
- 便携 ZIP 约 18.66 MiB，CRC 与 EXE / DLL 哈希一致，不包含工作区、测试数据与开发工具。

## 验证边界

已实机验证 Windows 11 x64；Windows 10 x64 是兼容构建目标，尚未在独立机器验证。磁盘耗尽、强制终止与缺少运行库的机器未做实机故障注入；应用提供事务回滚、重启中断标记和启动诊断。未宣称完整屏幕阅读器合规。

Excel 使用公式缓存，不重新计算公式。导出新工作簿，不复制原文件打印排版、宏和样式；原表渲染不包含图片、图形、复杂条件格式和逐字富文本。
